# Monitoring and Evaluation Framework

## 1. Overview

This folder contains the Monitoring and Evaluation (M&E) framework for the project titled **Reducing Malnutrition in Loima Sub-county, Turkana County**.

The framework provides a structured approach for planning, monitoring and evaluating project implementation and performance over a three-year period.

## 2. Objectives

- Establish the project goal, outcomes, outputs and activities.
- Develop a logical framework for project implementation.
- Define performance indicators and means of verification.
- Identify assumptions, risks and mitigation measures.
- Establish monitoring responsibilities and reporting schedules.
- Support evidence-based decision-making and accountability.

## 3. Contents

- `ME_framework_and_logical_framework.docx` – Contains the project theory of change, logical framework matrix, activities, monitoring plan, roles and responsibilities, data quality assurance, and risk management.

## 4. Key M&E Concepts Applied

- Results chain and theory of change
- Logical Framework Approach (Logframe)
- Results-Based Management (RBM)
- Performance measurement
- Means of verification
- Assumptions and risks
- Monitoring and reporting plans

## 5. Skills Demonstrated

- M&E framework development
- Project planning
- Logical framework development
- Results-based monitoring
- Risk identification and management
- Monitoring system design

## 6. Application

The framework demonstrates how M&E structures can guide public health, nutrition, community development and other development projects.
