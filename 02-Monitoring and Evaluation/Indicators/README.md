# M&E Indicators and Performance Tracking Tools

## 1. Overview

This folder contains tools for developing, defining and tracking project performance indicators.

The tools are designed for the project **Reducing Malnutrition in Loima Sub-county, Turkana County** and demonstrate how project progress can be measured against established targets.

## 2. Objectives

- Develop SMART performance indicators.
- Define indicators using clear measurement criteria.
- Establish baselines and targets.
- Track actual achievements against planned targets.
- Calculate indicator performance and variances.
- Assess data quality and identify reporting gaps.

## 3. Contents

- `ME_indicator_tracking_and_DQA_tool.xlsx` – An Excel workbook containing:
  - Logical Framework Matrix
  - Indicator Reference Sheet
  - Quarterly Indicator Tracking Tool
  - Data Quality Assessment Checklist
  - Risk Register

## 4. Key Concepts Applied

- SMART indicators
- Baseline and target setting
- Numerators and denominators
- Indicator measurement and calculation
- Performance tracking
- Data quality assessment
- Performance variance analysis

## 5. Skills Demonstrated

- Indicator development
- Excel-based M&E tracking
- Data management
- Performance measurement
- Data quality assessment
- Monitoring data analysis
- Results-based reporting

## 6. Application

These tools can support monitoring of public health programmes, nutrition interventions, NGO projects, community development initiatives and donor-funded programmes.

**Note:** All sample baselines and targets are illustrative. Actual project indicators and targets should be validated with relevant stakeholders.
