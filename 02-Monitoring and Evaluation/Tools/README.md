# M&E Data Collection and Supervision Tools

## 1. Overview

This folder contains practical data collection and monitoring tools designed to support the implementation of the project **Reducing Malnutrition in Loima Sub-county, Turkana County**.

The tools demonstrate how monitoring information can be collected, documented, verified and used to improve project performance.

## 2. Objectives

- Develop structured data collection tools.
- Standardize the recording of project activities.
- Support routine monitoring and supervision.
- Improve data completeness and accuracy.
- Facilitate referral follow-up and activity tracking.
- Collect community feedback for programme improvement.

## 3. Contents

- `ME_data_collection_and_supervision_tools.docx` – Contains five practical tools:

  1. Community Screening and Referral Summary
  2. Caregiver Nutrition Counselling Session Record
  3. Facility Monthly Reporting Checklist
  4. Supportive Supervision Checklist
  5. Community Feedback Log

## 4. Key Concepts Applied

- Primary data collection
- Structured monitoring tools
- Supportive supervision
- Data verification
- Referral tracking
- Community feedback mechanisms
- Data confidentiality and protection

## 5. Skills Demonstrated

- Data collection tool development
- Questionnaire and checklist design
- Monitoring tool development
- Data quality control
- Supportive supervision
- Documentation and reporting
- Data protection practices

## 6. Application

The tools can be adapted for healthcare programmes, community health interventions, nutrition projects, NGO activities and other monitoring and evaluation assignments.

**Note:** These are demonstration templates. Adapt them to approved project procedures and applicable Ministry of Health and county guidelines before field use. Do not store identifiable patient or caregiver information in public repositories.
