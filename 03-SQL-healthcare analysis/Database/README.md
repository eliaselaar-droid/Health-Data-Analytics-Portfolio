# Database

This folder contains the T-SQL scripts used to create the Hospital database and populate the `Patients` and `Visits` tables with synthetic example records.

## Files
- `01_create_database_and_tables.sql`: creates the database and relational tables, including keys and basic constraints.
- `02_insert_synthetic_data.sql`: inserts 20 synthetic patient records and 10 synthetic visit records.

## Run order
Run script 01, then script 02, in SQL Server Management Studio.
