# T-SQL Concepts Demonstrated

The uploaded learning script's main topics have been organised into this portfolio:

- Database and table creation: CREATE DATABASE, CREATE TABLE
- Data loading: INSERT INTO
- Retrieval and filtering: SELECT, WHERE, IN, BETWEEN, LIKE, IS NULL
- Sorting and distinct values: ORDER BY, DISTINCT
- Aliases: AS
- Aggregation: COUNT, SUM, AVG, MIN, MAX
- Grouped summaries: GROUP BY, HAVING
- Data relationships: INNER JOIN, LEFT JOIN, RIGHT JOIN, FULL OUTER JOIN
- Nested queries: subqueries, EXISTS, NOT EXISTS
- Conditional logic: CASE
- Text functions: UPPER, LOWER, LEN, LEFT, RIGHT, SUBSTRING, CONCAT, TRIM
- Date functions: YEAR, MONTH, DAY, GETDATE, DATEDIFF, DATEADD, DATEPART, EOMONTH, DATENAME
- Type conversion: CAST and CONVERT
- Reporting: CREATE OR ALTER VIEW
- Data quality: missing values, duplicate identifiers, validity and referential integrity

The package uses SQL Server-specific T-SQL syntax. It is not a MySQL or PostgreSQL project.
