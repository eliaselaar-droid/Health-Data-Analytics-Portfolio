# Data Dictionary

| Variable | Meaning | Coding / units |
|---|---|---|
| PatientID | Synthetic identifier | Unique numeric key |
| Age | Age in completed years | Years |
| GenderCode | Gender category | 1 Male; 2 Female |
| CountyCode | County | 1 Nairobi; 2 Kiambu; 3 Kisumu; 4 Turkana; 5 Nakuru; 6 Uasin Gishu |
| DiagnosisCode | Diagnosis group | 1 HIV; 2 Diabetes; 3 Hypertension; 4 Malaria; 5 Other |
| BMI | Body mass index | kg/m² |
| SystolicBP / DiastolicBP | Blood pressure | mmHg |
| FastingGlucose | Fasting glucose | mmol/L |
| LengthOfStayDays | Length of stay | Days |
| Readmission30d | Synthetic binary flag | 0 No; 1 Yes |
| FollowUpCompleted | Follow-up status | 0 No; 1 Yes |
| SatisfactionScore | Satisfaction rating | 1–5 ordinal score |

The category labels are illustrative, not a clinical coding standard. All records are synthetic.
