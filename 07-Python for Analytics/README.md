# Python Healthcare Data Analysis Portfolio

A complete Python portfolio project covering healthcare data loading, quality assessment, cleaning, exploratory analysis, visualisation, statistical testing and introductory machine learning.

## Dataset
600 synthetic patient records, plus five intentionally duplicated rows in the raw CSV. Missing values are intentionally present in selected fields for data-quality exercises. A cleaned CSV is included.

## Folders
- `data/`: raw and cleaned synthetic CSV files.
- `notebooks/`: guided Jupyter notebooks for quality, EDA and modelling.
- `scripts/`: reusable Python scripts for the full workflow.
- `visualizations/`: charts generated by the EDA script.
- `reports/`: report template and generated summaries.
- `documentation/`: data dictionary and methodology.

## Setup
Use Python 3.10+. Install dependencies with `pip install -r requirements.txt`. Open the project in VS Code or JupyterLab. Run notebooks 01, 02 and 03 in order, or execute scripts from the project root.

## Skills demonstrated
Pandas, NumPy, missing-value handling, duplicate detection, groupby, datetime analysis, Matplotlib, Seaborn, SciPy hypothesis tests, scikit-learn pipelines, one-hot encoding, logistic regression, confusion matrix and ROC-AUC.

**Important:** All records are synthetic. The readmission flag and model are educational demonstrations only, not clinically valid and not suitable for patient-care decisions.
